========================================
НОВАЯ СИСТЕМА РОЛЕЙ (2 роли)
========================================

Система упрощена до 2 ролей:

1. HR-МЕНЕДЖЕР (эйчар)
   - Суперпользователь (is_superuser = True)
   - Может просматривать всех сотрудников
   - Может создавать и управлять вакансиями
   - Может мониторить все обучения
   - Может формировать и выгружать отчёты
   - Доступ к админ-панели Django

2. ОБЫЧНЫЙ СОТРУДНИК
   - Может просматривать только свои обучения
   - Может просматривать детали своих обучений
   - Может скачивать свои сертификаты
   - Нет доступа к управлению данными

========================================
МИГРАЦИЯ БАЗЫ ДАННЫХ
========================================

Для применения изменений выполните:

python manage.py makemigrations hr
python manage.py migrate

Это обновит:
- Удалит роль 'admin' из choices
- Обновит всех пользователей с ролью 'admin' на 'hr_manager'

========================================
СОЗДАНИЕ HR-МЕНЕДЖЕРА
========================================

1. Создайте суперпользователя:
   python manage.py createsuperuser

2. Установите роль hr_manager:
   python manage.py shell
   
   >>> from hr.models import User
   >>> user = User.objects.get(username='ваш_логин')
   >>> user.role = 'hr_manager'
   >>> user.save()
   >>> exit()

Или используйте скрипт:
   python create_admin.py

========================================
ИЗМЕНЕНИЯ В КОДЕ
========================================

1. Модель User (hr/models.py):
   - Убрана роль 'admin'
   - is_hr_manager() проверяет is_superuser ИЛИ role == 'hr_manager'
   - is_employee() проверяет role == 'employee' И НЕ is_superuser

2. Views (hr/views.py):
   - Все проверки is_admin() заменены на is_hr_manager()
   - Обычные сотрудники могут видеть только свои обучения
   - trainings_list() показывает разные данные для HR и сотрудников

3. Middleware (hr/middleware.py):
   - Проверяет is_staff/is_superuser для админки
   - Разрешает доступ к /hr/trainings/ для всех (проверка в view)

4. Шаблоны:
   - Убраны все проверки is_admin
   - Обычные сотрудники видят пункт меню "Мои обучения"
   - HR-менеджеры видят полное меню
