========================================
КАК ВОЙТИ В АДМИН-ПАНЕЛЬ
========================================

ПРОБЛЕМА: Не могу зайти в админку

РЕШЕНИЕ:

Для доступа в админ-панель Django нужен пользователь с правами:
- is_superuser = True ИЛИ
- is_staff = True

========================================
СПОСОБ 1: Через команду Django (рекомендуется)
========================================

Выполните в командной строке:

python manage.py createsuperuser

Введите:
- Username (логин)
- Email address
- Password (пароль)

После этого пользователь будет иметь:
- is_superuser = True
- is_staff = True

НО! Роль (role) будет 'employee' по умолчанию.

Чтобы установить роль 'admin', выполните:

python create_admin.py

Или вручную через Python shell:

python manage.py shell

>>> from hr.models import User
>>> user = User.objects.get(username='ваш_логин')
>>> user.role = 'admin'
>>> user.save()

========================================
СПОСОБ 2: Через скрипт create_admin.py
========================================

Выполните:

python create_admin.py

Скрипт попросит ввести:
- Логин
- Email
- Пароль

И автоматически создаст пользователя с:
- is_superuser = True
- is_staff = True
- role = 'admin'

========================================
СПОСОБ 3: Изменить существующего пользователя
========================================

Если у вас уже есть пользователь, выполните:

python manage.py shell

>>> from hr.models import User
>>> user = User.objects.get(username='ваш_логин')
>>> user.is_superuser = True
>>> user.is_staff = True
>>> user.role = 'admin'
>>> user.save()
>>> exit()

========================================
ПРОВЕРКА ДОСТУПА
========================================

После создания администратора:

1. Откройте: http://127.0.0.1:8000/admin/
2. Введите логин и пароль
3. Вы должны попасть в админ-панель Django

========================================
ВАЖНО
========================================

- is_superuser или is_staff - для доступа в Django админку
- role = 'admin' - для доступа к функциям HR системы

Рекомендуется установить оба параметра!
