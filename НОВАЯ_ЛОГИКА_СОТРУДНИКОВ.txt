========================================
НОВАЯ ЛОГИКА: СОТРУДНИКИ ТОЛЬКО С АККАУНТАМИ
========================================

ИЗМЕНЕНИЯ:

1. СОЗДАНИЕ СОТРУДНИКА
   - Теперь ОБЯЗАТЕЛЬНО выбирать пользователя при создании
   - Можно выбрать только пользователей с ролью "Обычный сотрудник"
   - Показываются только пользователи, у которых еще НЕТ карточки сотрудника
   - Один пользователь = один сотрудник (OneToOne)

2. РЕДАКТИРОВАНИЕ СОТРУДНИКА
   - Можно изменить связанного пользователя
   - Показываются все пользователи с ролью "Обычный сотрудник"
   - Система проверяет, что пользователь не используется другим сотрудником

3. ОБУЧЕНИЕ
   - В обучение можно добавлять ТОЛЬКО сотрудников с аккаунтами
   - Добавлен поиск по участникам (имя, фамилия, email)
   - Показываются только сотрудники, у которых есть поле user

========================================
КАК РАБОТАЕТ СИСТЕМА:
========================================

ШАГ 1: Регистрация пользователя
--------------------------------
1. Пользователь регистрируется на платформе
2. Получает роль "Обычный сотрудник" (по умолчанию)
3. Теперь у него есть аккаунт, но еще нет карточки сотрудника

ШАГ 2: Создание карточки сотрудника
------------------------------------
1. HR-менеджер идет в "Сотрудники" → "Добавить сотрудника"
2. В форме ОБЯЗАТЕЛЬНО выбирает пользователя из списка
3. Заполняет остальные данные (имя, должность, отдел и т.д.)
4. Сотрудник создается и связывается с пользователем

ШАГ 3: Добавление в обучение
-----------------------------
1. HR-менеджер создает/редактирует обучение
2. В поле "Участники" видит ТОЛЬКО сотрудников с аккаунтами
3. Может использовать поиск для быстрого нахождения
4. Выбирает нужных сотрудников (Ctrl+Click для множественного выбора)

========================================
ВАЛИДАЦИЯ:
========================================

При создании сотрудника:
- Проверяется, что пользователь имеет роль "employee"
- Проверяется, что у пользователя еще нет карточки сотрудника
- Проверяется уникальность email

При редактировании сотрудника:
- Можно изменить связанного пользователя
- Проверяется, что новый пользователь не используется другим сотрудником

При добавлении в обучение:
- Показываются только сотрудники с user__isnull=False
- Нельзя добавить сотрудника без аккаунта

========================================
ВАЖНО:
========================================

- Нельзя создать сотрудника без пользователя
- Нельзя добавить в обучение сотрудника без аккаунта
- Один пользователь = один сотрудник
- Сначала регистрация → потом создание карточки сотрудника
