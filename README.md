# Система автоматизации отдела кадров

Веб-система для автоматизации задач отдела кадров, разработанная на Django.

## Функционал

### 👥 Управление сотрудниками
- Список сотрудников с поиском и фильтрацией
- Детальная информация о сотруднике
- CRUD операции (создание, редактирование, удаление)
- Фильтрация по отделу, должности, статусу
- Загрузка фотографий сотрудников

### 💼 Управление вакансиями
- Создание и управление вакансиями
- Изменение статуса вакансии (открыта/закрыта/архив)
- Поиск и фильтрация вакансий
- Привязка к отделам и должностям

### 🎓 Обучение сотрудников
- Создание учебных мероприятий
- Привязка сотрудников к обучению
- Отслеживание статуса обучения
- Загрузка сертификатов

### 📊 Отчётность
- Отчёт по вакансиям
- Отчёт по обучению сотрудников
- Штатное расписание
- Экспорт в форматах: CSV, XLSX, JSON

### 🔐 Безопасность
- Ролевая модель доступа (Администратор, HR-менеджер, Сотрудник)
- Валидация данных на клиенте и сервере
- Хеширование паролей (bcrypt)
- Защита от SQL-инъекций и XSS
- CSRF защита

## Технологии

- **Backend**: Django 4.2.7
- **База данных**: SQLite (разработка) / PostgreSQL / MySQL
- **Frontend**: HTML5, CSS3, JavaScript
- **Библиотеки**: openpyxl (для Excel), Pillow (для изображений)

## Установка и запуск

### Требования
- Python 3.8+
- pip

### Шаг 1: Установка зависимостей

```bash
pip install -r requirements.txt
```

### Шаг 2: Настройка базы данных

Выполните миграции для создания таблиц:

```bash
python manage.py makemigrations
python manage.py migrate
```

### Шаг 3: Создание суперпользователя (опционально)

```bash
python manage.py createsuperuser
```

Или создайте пользователя через регистрацию на сайте.

### Шаг 4: Запуск сервера

```bash
python manage.py runserver
```

Откройте браузер и перейдите по адресу: `http://127.0.0.1:8000/`

## Модели данных

### User (Пользователь)
- Расширенная модель пользователя Django
- Роли: admin, hr_manager, employee
- Email, телефон, имя, фамилия

### Employee (Сотрудник)
- Личная информация
- Должность и отдел
- Статус (работает, в отпуске, на больничном, уволен)
- Фото

### Vacancy (Вакансия)
- Название и описание
- Зарплата (от/до)
- Статус (открыта/закрыта/архив)
- HR-менеджер, отдел, должность

### Training (Обучение)
- Название и описание
- Даты начала и окончания
- Статус (запланировано/в процессе/завершено/отменено)
- Участники (Many-to-Many)
- Ответственный

### Certificate (Сертификат)
- Связь сотрудника и обучения
- Загруженный документ
- Дата выдачи

## API Endpoints

### Аутентификация
- `GET/POST /register/` - Регистрация
- `GET/POST /login/` - Вход
- `POST /logout/` - Выход

### Сотрудники
- `GET /employees/` - Список сотрудников
- `GET /employees/<id>/` - Детали сотрудника
- `GET/POST /employees/create/` - Создание сотрудника
- `GET/POST /employees/<id>/edit/` - Редактирование
- `GET/POST /employees/<id>/delete/` - Удаление

### Вакансии
- `GET /vacancies/` - Список вакансий
- `GET /vacancies/<id>/` - Детали вакансии
- `GET/POST /vacancies/create/` - Создание вакансии
- `GET/POST /vacancies/<id>/edit/` - Редактирование
- `GET/POST /vacancies/<id>/delete/` - Удаление

### Обучение
- `GET /trainings/` - Список обучения
- `GET /trainings/<id>/` - Детали обучения
- `GET/POST /trainings/create/` - Создание обучения
- `GET/POST /trainings/<id>/edit/` - Редактирование
- `GET/POST /trainings/<id>/delete/` - Удаление

### Отчёты
- `GET /reports/` - Страница отчётов
- `GET /reports/vacancies/?format=csv|xlsx|json` - Отчёт по вакансиям
- `GET /reports/training/?format=csv|xlsx|json` - Отчёт по обучению
- `GET /reports/staffing/?format=csv|xlsx|json` - Штатное расписание

## Интеграция с Telegram-ботом

Проект включает встроенную интеграцию с Telegram: уведомления отправляются при изменениях в карточках сотрудников, назначениях обучения и других событиях HR.

Переменные окружения (можно положить в `.env` или в окружение сервера):

- `TELEGRAM_BOT_TOKEN` — токен бота от BotFather (обязателен для отправки сообщений).
- `TELEGRAM_WEBHOOK_SECRET` — секрет для webhook (если используете webhook).
- `SITE_BASE_URL` — базовый URL вашего сайта (для ссылок "Открыть в системе").
- `TELEGRAM_AUTO_POLL` — `true|false`, включает фоновый polling при запуске сервера (по умолчанию `true`).

Запуск в режиме polling (удобно для разработки, не требует внешнего SSL):

```bash
# через обычный runserver (в DEBUG polling запускается автоматически, если TELEGRAM_AUTO_POLL=true)
python manage.py runserver

# или запустить отдельный polling-скрипт
./run_telegram_poll.sh
```

Запуск в режиме webhook (рекомендуется для продакшена):

1. Настройте HTTPS и получите публичный URL для `SITE_BASE_URL`.
2. Установите `TELEGRAM_WEBHOOK_SECRET` и запустите сервер.
3. Зарегистрируйте webhook у Telegram (пример):

```bash
curl -F "url=https://your.domain/hr/integrations/telegram/webhook/" https://api.telegram.org/bot$TELEGRAM_BOT_TOKEN/setWebhook
```

Пара полезных команд для отладки и тестов:

```bash
# Запуск тестов Telegram
python manage.py test hr.tests_telegram

# Проверить, что бот отправляет сообщения (в тестах используется мок)
```

Автозапуск обучений (рекомендуется настроить cron или systemd timer):

```bash
# Запустить задания на старте для сегодняшней даты
python manage.py start_scheduled_trainings

# Запустить для всех просроченных и сегодняшних (force)
python manage.py start_scheduled_trainings --force
```

Рекомендуем запускать команду ежедневно (00:05), чтобы обучения с датой начала сегодня автоматически переводились в статус "в процессе" и участникам были отправлены уведомления.

Если нужно, подготовлю короткую инструкцию по развёртыванию webhook на сервер (systemd/nginx/certbot) и пример `docker-compose`.
