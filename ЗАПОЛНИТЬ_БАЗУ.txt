ИНСТРУКЦИЯ ПО ЗАПОЛНЕНИЮ БАЗЫ ДАННЫХ

Вариант 1 (через Django shell):
1. Откройте терминал в папке проекта
2. Запустите: python manage.py shell
3. Скопируйте и вставьте код из файла seed_data.py

Вариант 2 (через Django management команду):
1. Откройте терминал в папке проекта  
2. Запустите: python manage.py seed_advertising_agency

Вариант 3 (через Python скрипт):
1. Откройте терминал в папке проекта
2. Запустите: python fill_advertising_agency_data.py

После выполнения в базе будут созданы:
- 6 отделов (креатив, продажи, медиапланирование, производство, маркетинг, клиентский сервис)
- 18 должностей (креативный директор, арт-директор, дизайнер, копирайтер и др.)
- 8 сотрудников (примеры)
